# Changelog

- Uses Yellow Together as the default background for new installations.
- Adds a discoverable Codex wallpaper-selector skill with gallery previews.

- Adds Codex marketplace installation, a one-line installer, and a double-click installer.
- Adds backup, U7-safe switching, restore, status, and uninstall flows.
